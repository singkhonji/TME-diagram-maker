# TME Diagram Maker

กรอกตาราง **System Diagram → Schematic Table** ใน Cubicost TME อัตโนมัติจากไฟล์ Excel
แทนการพิมพ์ทีละช่องจากไดอะแกรม SLD ซึ่งต้องทำซ้ำ 100–200 ตู้ต่อโปรเจกต์

ทุกค่าที่เขียนถูกอ่านกลับมาตรวจ และหยุดทันทีเมื่อเจอสิ่งที่อธิบายไม่ได้ — ไม่ปล่อยให้เขียนผิดสะสมโดยไม่มีคนเฝ้า

**สถานะ: ใช้งานได้จริง ทดสอบผ่านแล้ว** — 3 ตู้ (ตู้แม่ 1 + ตู้ลูก 2) 41 circuit
ใน 98 วินาที ตรงทุกช่อง และลำดับชั้นตู้แม่-ตู้ลูกถูกต้องใน Schematic Tree

---

## ต้องมีอะไรบ้าง

- Windows + **Cubicost TME C**
- Python 3.10 ขึ้นไป
- จอเดียวก็พอ แต่ระหว่างรันห้ามใช้เมาส์/คีย์บอร์ดแย่งหน้าต่าง TME

```bash
git clone https://github.com/singkhonji/TME-diagram-maker.git
cd TME-diagram-maker
pip install -r requirements.txt
```

## Excel Template — สำคัญที่สุด

**ต้องใช้ template นี้เท่านั้น** เพราะตำแหน่งคอลัมน์ทั้งหมดอ้างอิงจากแถวหัวตาราง
ถ้าหัวตารางไม่ตรงกับ 9 คอลัมน์ของ TME ทุกตัวอักษร โปรแกรมจะปฏิเสธไม่ยอมรัน

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| [`templates/schedule-template.xlsx`](templates/schedule-template.xlsx) | **ไฟล์เปล่าพร้อมกรอก** มีชีต "วิธีใช้" อธิบายทุกกฎอยู่ในไฟล์ |
| [`examples/example-schedule.xlsx`](examples/example-schedule.xlsx) | ตัวอย่างที่กรอกครบ มีทั้งแถวปกติ SPARE และตู้แม่-ตู้ลูก |

### กติกาของตาราง

| คอลัมน์ | ใส่อะไร |
|---|---|
| **A** Name | **แถวตู้**: ชื่อตู้ (คอลัมน์นี้คอลัมน์เดียว ที่เหลือเว้นว่าง)<br>**แถว circuit**: `[AUTO GENERATED BY ROW B]` เพราะ TME สร้างชื่อเองเป็น `<ชื่อตู้>-<Circuit Number>` |
| **B** Circuit Number | กรอก |
| **C** Cable Specification | กรอก · แถวว่างใส่ `SPARE` |
| **D** Terminal Load | กรอก เช่น `20A` · **หรือใส่ชื่อตู้ลูก** ถ้าเป็น circuit ของตู้แม่ |
| **E** Corresponding Element | `[SKIP]` = ใช้ค่า default ของ TME |
| **F** Conduit Size (mm) | เว้นว่างเสมอ (กรอกเองใน TME ทีหลัง) |
| **G** Elevation (m) | `[SKIP]` |
| **H** System | กรอก · แถว SPARE เว้นว่างได้ ระบบเติมให้ตรงกับแถวอื่นในตู้เดียวกัน |
| **I** Remarks | กรอกถ้ามี · แถว SPARE ปล่อยว่าง |

### ตู้แม่ / ตู้ลูก

ใส่ **ชื่อตู้ลูก** ในคอลัมน์ `Terminal Load` ของ circuit ในตู้แม่ แทนค่ากระแส
TME จะผูกลำดับชั้นให้เองใน Schematic Tree

**เรียงตู้ลูกไว้ก่อนตู้แม่เสมอ** เพราะตู้ลูกต้องมีอยู่จริงก่อนตู้แม่จะอ้างถึงได้

```
MSB-Y2
 F1  4x1C 50sq.mm. ──► DB-Y2-GF-WH1
 F2  4x1C 50sq.mm. ──► DB-Y2-GF-WH2
```

## แกะ Excel จากแบบ SLD (PDF)

ถ้ายังไม่มี Excel และมีแต่แบบ Load Diagram เป็น PDF ใช้เส้นทางนี้ก่อน

แบบที่ export จาก AutoCAD **ไม่มี text layer** — ตัวหนังสือถูกแปลงเป็นเส้นโค้งหมด
(`pdfplumber` อ่านได้ 0 ตัวอักษรต่อหน้า, `pdftotext` คืนค่าว่าง)
→ ดึงข้อความด้วยโค้ดไม่ได้ ต้อง render เป็นภาพแล้วอ่านด้วยตา

```bash
python -m tme.cli.pdfcrop "01 BLD_Y1 Only Load Diagram.pdf" 2 --box 0.05 0.03 0.26 0.26 --scale 2.6
```

`--box L T R B` เป็นสัดส่วนของหน้า (0–1 นับจากมุมบนซ้าย) · `--scale 2.6` ≈ 190 DPI อ่านตัวหนังสือในแบบ A1 ออกชัด
คำอธิบายโหลดกับ cable spec ในแบบวางตั้ง อ่านจากล่างขึ้นบน → ใส่ `--rotate cw` แล้วจะอ่านเป็นแนวนอนปกติ
`--grid ROWS COLS` แบ่งทั้งหน้าเป็น tile ให้อัตโนมัติ

สิ่งที่อ่านได้บันทึกลง `projects/<ลูกค้า>/buildings/<อาคาร>/drawing.yaml` ซึ่งเขียนตามรูปแบบที่แบบมาร์กไว้จริง —
กลุ่มวงจรที่ใช้คำอธิบายโหลด พิกัด breaker และสายชุดเดียวกันอยู่ในกลุ่มเดียว จึงตรวจทานเทียบกับแบบได้ตรงๆ
ไม่ต้องไล่ทีละแถวใน spreadsheet

```yaml
- name: DB-Y1-GF-WH1-2
  system: Power System
  sections:
    - prefix: L                       # เติมหน้าเลขวงจร -> L-R1
      system: Lighting System
      cable: "2 X 1C 2.5mm2 PVC CU CABLE + E IN G.I CONDUIT/TRUNKING."
      groups:
        - refs: [R1, Y1, B1, R2, Y2]
          load: "6 NOS 250W LED HIGH BAY"
          rating: 20A
        - refs: [B7, R8, Y8, B8]
          spare: true
          rating: 10A
- name: MSB-Y1
  sections:
    - prefix: ""
      groups:
        - refs: [RYB3]
          to: DB-Y1-GF-WH1-2          # ชื่อตู้ลูกลงคอลัมน์ Terminal Load
          rating: 200A
          cable: "4 x 1C 95mm:sq XLPE/PVC + E CU C IN HDG. TRAY/TRUNKING"
```

แล้วสร้าง Excel:

```bash
python -m tme.cli.build projects/mrdiy/buildings/Y1
```

ตัวสร้างจัดการให้เอง 3 อย่างที่พลาดง่ายถ้าทำมือ

| เรื่อง | ทำอะไรให้ |
|---|---|
| **เลขวงจรซ้ำในตู้เดียว** | ตู้ DB แบ่งเป็น section `L` / `P` / `AC` และ `R1 Y1 B1` เริ่มใหม่ทุก section → เติม prefix เป็น `L-R1`, `P-R1`, `AC-R1` เพราะ TME ตั้งชื่อแถวเป็น `<ชื่อตู้>-<Circuit Number>` ถ้าซ้ำจะพัง |
| **ลำดับตู้ลูกก่อนตู้แม่** | เรียงด้วย topological sort จาก field `to` — TME ผูกตู้ลูกได้ก็ต่อเมื่อตู้ลูกมีอยู่จริงแล้ว |
| **ตรวจไฟล์ที่ตัวเองเขียน** | อ่านกลับผ่าน `tme.schedule.reader.load_boards()` (ตัวเดียวกับที่ตัวกรอกใช้) แล้ว fail ถ้ามี warning |

### กับดักตอนอ่านแบบ

- **พิกัด breaker ใช้เครื่องหมายซ้ำ (`=`)** ระบุ `20A SPN MCB` ครั้งเดียว แถวถัดไปเป็น `=` จนกว่าจะระบุค่าใหม่ ·
  ป้ายพิกัดวางอยู่ **ซ้ายมือของ breaker ที่มันเป็นเจ้าของ** ไม่ใช่ขวา — อ่านสลับข้างแล้วพิกัดจะเลื่อนไปทั้งแถว
- **ป้าย cable spec อาจเรียงกลับด้านกับกลุ่มวงจรที่มันจ่าย** บน MSB-Y1 ป้ายเรียงซ้าย→ขวาเป็น 6/25/95/50 mm²
  แต่ป้าย**ขวาสุด**ลากไปเส้นแนวนอน**บนสุด** ซึ่งจ่ายวงจร**ซ้ายสุด** → ต้องไล่ตามความสูงของเส้นแนวนอนทีละเส้น
  แล้วตรวจสมเหตุสมผลกับพิกัด breaker เสมอ (50mm² คู่กับ 100A, 6mm² คู่กับ 30A)
- **ชื่อตู้ซ้ำกันได้ในแบบเดียวกัน** Y1 มี `DB-Y1-GF-WH1` สองตู้และ `DB-Y1-GF-WH2` สองตู้ คนละโหลด คนละ TCL
  ต้องแยกชื่อก่อน (ที่นี่ใช้ `-1` / `-2` ตามลำดับที่ปรากฏบน busbar ของตู้แม่) ไม่งั้น TME เด้งถาม Merge/New แล้วค้าง

## วิธีใช้

**1. ตรวจ Excel ก่อน** (ไม่ต้องเปิด TME — ทำได้ตั้งแต่ยังไม่ถึงหน้างาน)

```bash
python -m tme.schedule.reader projects/mrdiy/buildings/Y1/schedule.xlsx --report
```

ต้องขึ้น `no warnings` ก่อนจึงจะรันจริงได้ ตัวตรวจจะเตือนถ้าเจอ **ชื่อตู้ซ้ำ**
(TME จะเด้งถาม Merge/New แล้วค้าง) หรือเซลล์ที่มี **tab/newline** (paste แล้วเพี้ยน)

**2. เตรียม TME**

- เปิดโปรเจกต์ → **สำรองไฟล์โปรเจกต์ไว้ก่อน** (TME ไม่มี undo — อ่านหัวข้อข้างล่าง)
- กด **System Diagram** → **ขยายหน้าต่างให้เต็มจอ**
- **คลิก 1 ครั้งในพื้นที่ตาราง** เพื่อให้ตารางได้ keyboard focus
  ถ้าลืม โปรแกรมจะไม่พิมพ์อะไรเลยและบอกให้คลิกก่อน (ไม่พิมพ์มั่ว)
- ปิดโปรแกรมที่ชอบเด้ง popup แทรก (Teams, Windows Update)

**3. รัน**

```bash
python -m tme.cli.fill_all projects/mrdiy/buildings/Y1
```

รันทีละตู้ ตู้ละหนึ่ง process ลำดับอ่านจาก workbook เอง (ตู้ลูกก่อนตู้แม่) หยุดที่ตู้แรกที่พัง
log เขียนลง `<โฟลเดอร์อาคาร>/runs/fill.log` · `--from BOARD` รันต่อจากตู้ที่ค้าง ·
`--dry-run` พิมพ์ลำดับตู้เฉยๆ ไม่แตะ TME

ถ้าจะรันตู้เดียวหรือใช้ตัวเลือกละเอียด ใช้ `tme.cli.fill` ตรงๆ:

```bash
python -m tme.cli.fill projects/mrdiy/buildings/Y1 --start-at MSB-Y1 --limit-boards 1
```

| ตัวเลือก | ทำอะไร |
|---|---|
| `--dry-run` | พิมพ์ลำดับคีย์และค่าทั้งหมดออกมาดู โดยไม่แตะ TME |
| `--limit-boards 1` | ทำแค่ตู้แรก — ใช้ตอนลองครั้งแรก |
| `--limit-rows 3` | ทำแค่ 3 แถวแรกของแต่ละตู้ |
| `--auto-dismiss-save` | ตอบ No ให้ popup `"Save current project?"` เองแล้วรันต่อ (ดูข้างล่าง) |
| `--force` | รันทั้งที่ Excel มี warning |

**กด `F12` หยุดได้ทันทีตลอดเวลา** แม้ TME กำลัง focus อยู่

**4. ตรวจด้วยตา แล้วกด OK เอง** — โปรแกรมไม่กด OK ให้เด็ดขาด

## ⚠️ TME ไม่มี undo

แถวถูกบันทึกเข้า model **ทันทีที่สร้าง** — ทั้งปุ่ม `Esc` และปุ่ม **Cancel** ก็ไม่ลบให้
ถ้ารันผิดต้องลบด้วยมือ:

```bash
python -m tme.tools.delete_boards       # ลบตู้บนสุด
python -m tme.tools.delete_boards 5     # ลบได้ถึง 5 ตู้ หยุดเองเมื่อตารางว่าง
```

**สำรองไฟล์โปรเจกต์ก่อนรันจริงทุกครั้ง**

## เมื่อหยุดกลางคัน

โปรแกรมจะบอกตำแหน่งชัดเจน (ตู้ / แถว / คอลัมน์ / ค่าที่ควรได้ vs ที่ได้จริง) เขียน `runs/state.json` ไว้
และถ้าเป็นเพราะมี popup มาบัง จะ**ถ่ายรูป popup นั้นเก็บไว้ให้** ที่ `runs/interrupted_by.png`
ทั้งคู่อยู่ในโฟลเดอร์อาคารที่รัน ไม่ปนกับอาคารอื่น

**ก่อนรันตู้เดิมซ้ำ ต้องลบตู้ที่กรอกค้างก่อน** ด้วย `tme.tools.delete_boards`
เพราะไม่มี undo และชื่อตู้ซ้ำจะทำให้ TME เด้งถาม Merge/New

### popup "Save current project?"

TME เด้งอันนี้ขึ้นมาเองเป็นระยะ และปุ่ม default คือ **Yes** ปกติโปรแกรมจะหยุดรอให้คุณตัดสินใจ
ถ้าไม่อยากให้ขัดจังหวะ ใช้ `--auto-dismiss-save` แล้วมันจะตอบ **No** ให้เองแล้วรันต่อ

ตัวเลือกนี้จะกด**เฉพาะ popup ตัวนี้ตัวเดียว** โดยตรวจสอบ 3 ชั้น: ชื่อหน้าต่าง, เจ้าของหน้าต่างต้องเป็น TME,
และ**เทียบภาพหน้าต่างกับรูปต้นแบบ** (`save_prompt_reference.png`) ถ้าไม่ตรงทั้งหมดจะไม่กดและหยุดตามปกติ —
เพราะ TME ใช้ชื่อหน้าต่างว่า `OK` กับคำถาม Yes/No อื่นด้วย การกดปุ่มใน dialog ที่ไม่มีใครอ่านคือสิ่งที่โปรแกรมนี้จะไม่ทำ

ทดสอบเส้นทางนี้ครบแล้ว: จดจำจากภาพ → คลิก → รอปิด → ดึง focus กลับตาราง → รันต่อจนจบ

## ทำไมต้องซับซ้อนขนาดนี้

Schematic Table เป็น **custom canvas** — `ControlType: Custom(50025)`, ไม่มี Name, ไม่ focusable
→ **UI Automation อ่าน/เขียนไม่ได้เลย** เหลือทางเดียวคือส่งคีย์บอร์ดจำลอง + อ่านค่ากลับผ่าน clipboard

ทุกข้อข้างล่างมาจากการทดลองจริงกับ TME ไม่ใช่การเดา — และหลายข้อเป็นกับดักที่ทำให้ข้อมูลเสียหายแบบเงียบๆ

### ใช้ได้

| พฤติกรรม | รายละเอียด |
|---|---|
| `Ctrl+I` เพิ่มตู้ | focus ไปแถวใหม่ แต่**ค้างอยู่คอลัมน์เดิม** → ต้อง `Ctrl+Left` ก่อนเสมอ · แถมแถว circuit ให้ 1 แถว |
| `Ctrl+R` เพิ่ม circuit | ใต้ตู้ปัจจุบัน |
| `F2` เปิด editor | **เลือกข้อความเดิมทั้งหมดให้ด้วย** → paste ทับได้เลย ไม่ต้อง `Ctrl+A` |
| `Enter` | commit แล้ว focus **ค้างที่ cell เดิม** |
| ลูกศรซ้าย/ขวา และ `Tab` | เลื่อน 1 คอลัมน์เท่ากัน · `Ctrl+Left` กลับคอลัมน์แรก |
| `System` (dropdown) | รับ paste ข้อความตรงๆ ได้ |
| Auto-scroll | ตารางเลื่อนตาม focus เอง — ทดสอบที่แถวลึกเกินหน้าจอ 28 แถว เขียน/อ่านได้ปกติ |

### ใช้ไม่ได้ / อันตราย

| เรื่อง | สิ่งที่เกิดขึ้น |
|---|---|
| 🔴 `Esc` ตอนไม่ได้อยู่ใน edit mode | **ปิด dialog ทั้งบาน** — โปรแกรมจะกด `Esc` ก็ต่อเมื่ออ่าน cell สำเร็จแล้วเท่านั้น (เป็นหลักฐานว่ามี editor เปิดอยู่จริง) |
| 🔴 `Ctrl+A` ตอนไม่ได้อยู่ใน edit mode | **เลือกทุกแถวในตาราง** แล้ว paste ถัดไปทับรัวทั้งตาราง → **ถอดออกทั้งหมด ไม่ส่งคีย์นี้เลย** |
| 🔴 `Esc` และปุ่ม `Cancel` | **ไม่ลบข้อมูล** — ไม่มี undo |
| 🔴 ปุ่ม `Del` | ไม่ทำอะไรเลย — ลบได้ทางปุ่ม **Delete Row** บน toolbar เท่านั้น |
| ⚠️ `F2` บน Elevation | `"Elevation input error"` |
| ⚠️ `F2` บน Conduit Size | `"Please enter an integer between [10,5000]"` |
| ⚠️ ชื่อตู้ซ้ำ | เด้งถาม **Merge / New** ค้างรอ |
| ⚠️ `System` เป็น dropdown | หลัง Enter มันค้างเปิด ทำให้ลูกศรถูกกินและค่าถัดไปเขียนทับช่องเดิม |
| ❌ paste แบบ TSV | tab กลายเป็น space แล้วลงช่องเดียว — เขียนทีละ cell เท่านั้น |
| ❌ `Ctrl+C` เปล่าๆ (Copy Row) | ไม่ตอบอะไร — อ่านทั้งแถวทีเดียวไม่ได้ |
| ❌ cell ว่าง | `Ctrl+C` เงียบสนิท **แยกไม่ออกจาก "copy ล้มเหลว"** → พิสูจน์ว่า cell ว่างไม่ได้ |
| ⚠️ มี popup ค้างแล้วกด `Ctrl+C` | Windows จะ copy **ข้อความของ popup** ลง clipboard แทนค่าใน cell → โปรแกรมรู้จักรูปแบบนี้ จัดการ popup แล้วอ่านใหม่ ไม่ตีความเป็น "ค่าผิด" |
| ⚠️ กด **New** ตอนชื่อตู้ซ้ำ | TME ตั้งชื่อใหม่ให้เองเป็น `<ชื่อเดิม>-1` ซึ่งไม่ตรงกับ Excel → ระบบจับได้และหยุด |
| ⚠️ เจ้าของหน้าต่าง popup ไม่เหมือนกัน | save prompt เป็นของหน้าต่างหลัก ส่วนคำถามจากตารางเป็นของหน้าต่าง System Diagram — ต้องรับทั้งสองแบบ |
| 🔴 `Ctrl+Left` **ไม่แน่นอน** | บางครั้งไปหยุดที่ **Circuit Number** ไม่ใช่ Name — ขาดไป 1 คอลัมน์ · เกิดเป็นครั้งคราว ลำดับคีย์เหมือนกันเป๊ะกับแถวที่ทำงานถูก ต่างกันแค่ read ก่อนหน้าใช้เวลา 0 ms แทน 27 ms · ผลคือ row sweep อ่านเลื่อนทั้งแถว → รายงานผิดทั้งที่แถวถูก → retry เขียนทับจากตำแหน่งเพี้ยน **แถวพังตอน retry ไม่ใช่ตอนเขียน** · แก้ด้วยการกด `Left` ต่ออีก 2 ครั้ง (วัดแล้ว: `Left` ที่คอลัมน์แรกไม่ทำอะไร กด 3 ครั้งยังอยู่ที่เดิม) |
| 🔴 อ่านเซลล์ที่ควรว่างในคอลัมน์กลางแถว | `F2` เปิด editor แล้ว `Ctrl+C` เงียบ → timeout → **ห้ามกด Esc** (พิสูจน์ไม่ได้ว่ามี editor เปิด) → editor ค้าง → `right` ตัวถัดไปเข้าไปใน editor ทั้งแถวเลื่อน · ช่องว่างในคอลัมน์**สุดท้าย** (Remarks ของแถว SPARE) ไม่พังเพราะไม่มีอะไรตามหลัง · **เลิกอ่านเซลล์ที่ควรว่างไปเลย** — อ่านไปก็พิสูจน์อะไรไม่ได้ ส่วนการพิสูจน์คอลัมน์ยังใช้เซลล์ Name อยู่ |

### Clipboard race

TME copy ด้วย `EmptyClipboard()` แล้วค่อย `SetClipboardData()` — ถ้าอ่าน clipboard ระหว่างกลางแล้วตีความว่า
"ตอบแล้ว" ทุกอย่างจะเหลื่อมกันทั้งกระบวนการ (เคยทำให้ค่าภายในหลุดเข้าไปอยู่ใน cell จริง)
→ clipboard ว่าง = **ยังไม่ตอบ** ไม่ใช่คำตอบ · และยืนยันเนื้อ clipboard ทุกครั้งก่อน paste

## กันพลาดอย่างไร

**ไม่มี `sleep()` แบบเดาเวลาเลยแม้แต่จุดเดียว** ทุกจังหวะรอด้วยการ poll clipboard จนกว่า TME จะตอบ
แอปหนืด 800 ms ก็รอ 800 ms พอดี — และปรับความเร็วเองตาม latency ที่วัดได้จริง

| ชั้น | จับอะไร |
|---|---|
| Focus guard | หน้าต่างอื่นแย่ง focus → หยุด + ถ่ายรูป popup เก็บไว้ให้ |
| อ่านกลับทุก cell ทันทีหลังเขียน | ค่าไม่เข้า · และบังคับปิด dropdown ที่ค้าง |
| ตรวจทั้งแถวหลังเขียนจบ | **ค่าไปลงผิดคอลัมน์** — ใช้ Name (`<ตู้>-<circuit>`) ที่ TME สร้างเองเป็นหลักฐาน |
| ตรวจแถวก่อนหน้า | คีย์เพิ่มแถวถูกกลืน แล้วเขียนทับแถวเดิม (อย่างอื่นจับไม่ได้ เพราะแถวนั้นอ่านกลับมาถูกทุกช่อง) |
| Retry 1 ครั้ง | สะดุดชั่วคราว |
| `F12` | หยุดทันที |

## ความเร็ว

2.4 วินาที/แถว → โปรเจกต์จริง 200 ตู้ × ~20 circuit ≈ **4,000 แถว ≈ 2.5–3 ชั่วโมง รันทิ้งไว้ได้**

เวลาส่วนใหญ่หมดไปกับการอ่านกลับเพื่อยืนยัน (~12 ครั้ง/แถว) ซึ่งเป็นสิ่งที่จับบั๊กค่าเลื่อนคอลัมน์ได้จริงมาแล้ว

## นอกขอบเขต

- `Conduit Size (mm)` และ `Remarks` ที่ต้องใช้ประสบการณ์หน้างาน
- Attribute ของตู้ (Type / Width / Height / Thickness / Elevation) ในแผงซ้าย
- Mapping `Circuit Number prefix → System` (ตอนนี้อ่านค่าจากคอลัมน์ H ใน Excel ตรงๆ)

## ใช้ร่วมกับ Claude Code

โปรเจกต์นี้พัฒนาด้วย [Claude Code](https://claude.com/claude-code) และตั้งใจให้ใช้ต่อแบบนั้น
พฤติกรรมของ TME ทั้งหมดที่วัดได้ถูกบันทึกไว้ใน docstring ของแต่ละไฟล์ ไม่ใช่แค่ README
เพื่อให้ Claude อ่านแล้วเข้าใจว่า**ทำไม**ถึงเขียนแบบนี้ และไม่เผลอ "ปรับให้ง่ายขึ้น" จนกลับไปเจอกับดักเดิม

เปิด Claude Code ที่โฟลเดอร์นี้แล้วสั่งได้เลย เช่น

- *"รัน `--dry-run` กับ Excel ไฟล์นี้แล้วบอกหน่อยว่ามีปัญหาอะไรไหม"*
- *"มันหยุดที่ตู้ DB-... ช่วยดู `runs/state.json` กับ `runs/interrupted_by.png` ให้หน่อย"*
- *"เพิ่มการรองรับคอลัมน์ Conduit Size"*

`tme.tools.probe` คือชุดวัดพฤติกรรม TME — ถ้า TME อัปเดตเวอร์ชันแล้วอะไรเพี้ยน ให้รันตัวนี้กับ
**โปรเจกต์ทดสอบเปล่า** ก่อน แล้วเทียบผลกับตารางข้างบน

### ข้อมูลลูกค้า — `projects/` (gitignore ทั้งก้อน)

| ไฟล์ | หน้าที่ |
|---|---|
| `projects/<ลูกค้า>/project.yaml` | ข้อตกลงระดับโครงการ (ชื่อลูกค้า, System ของช่อง SPARE) |

## เทสต์

```bash
python -m pytest
```

ครอบ 4 อย่าง และที่สำคัญกว่าคือรู้ว่า**ไม่**ครอบอะไร:

- ทุกโมดูล import ผ่าน
- `RunPaths` ชี้ตำแหน่งผลรันถูก และ `project.yaml` ถูกอ่านจริง
- สร้าง Excel ใหม่จาก YAML ของแต่ละอาคาร แล้วได้ตรงกับไฟล์ที่อนุมัติแล้วทุกเซลล์
- `load_boards` คืนตู้ จำนวนวงจร และ warning เท่าเดิม

เทสต์ golden กับ snapshot ต้องมีข้อมูลใน `projects/` ถ้าไม่มีจะ skip พร้อมข้อความ —
clone ที่ไม่มีข้อมูลลูกค้าคือ clone ที่ถูกต้อง

**ตั้งแต่ `tme/grid.py` เข้าไปไม่มีอะไรครอบเลย** ไม่มีเทสต์ไหนขับ TME ได้
รันจริงครั้งแรกหลังแก้ `tme/win/` หรือ `tme/grid.py` ให้รัน**ตู้เดียว** บนไฟล์โปรเจกต์ที่สำรองแล้ว
และมีคนนั่งดู — ไม่ใช่ซัดรวด 16 ตู้
